# Frontend Design
## Overview
Pulls AI output away from generic defaults (Inter font, purple gradient, grid cards) toward distinctive, considered design.
## When to Activate
- Building new user interfaces
- Reshaping existing UI designs
- Internal tools, reports, dashboards
## Guidelines
1. Avoid generic defaults
2. Typography - choose fonts intentionally
3. Color with purpose - curated, harmonious palettes
4. Visual hierarchy - clear information architecture
5. Spacing and rhythm - consistent whitespace
6. Component design - reusable, cohesive systems
7. Responsive first
8. Micro-interactions - subtle animations
9. Accessibility - WCAG compliance
