# Writing Plans
## Overview
Creates detailed implementation plans that are clear enough for an agent to execute autonomously.
## Plan Structure
1. Goal statement
2. Prerequisites
3. Step-by-step tasks with clear acceptance criteria
4. Testing strategy
5. Edge cases and error handling
6. Review points
