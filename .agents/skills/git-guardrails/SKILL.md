# Git Guardrails
## Overview
Prevents accidental destructive git operations like force-pushing to main, deleting important branches, or committing sensitive data.
## Rules
- Never force push to main/master
- Always create feature branches
- Check for sensitive data before commits
- Verify branch before destructive operations
