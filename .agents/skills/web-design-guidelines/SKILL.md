# Web Design Guidelines
## Overview
Reviews what you have already built against Vercel interface guidelines. Use at the END of a UI session, not the beginning.
## Audit Checklist
1. Visual Hierarchy - is information architecture clear?
2. Spacing - consistent and purposeful whitespace?
3. Typography - coherent font sizes, weights, line heights?
4. Color - meets contrast requirements?
5. Responsiveness - works across viewport sizes?
6. Accessibility - interactive elements properly labeled?
7. Consistency - similar elements look and behave the same?
