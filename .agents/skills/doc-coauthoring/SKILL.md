# Doc Co-Authoring
## Process
1. Transfer context - understand the topic and audience
2. Build outline - structure the document
3. Get sign-off - approve structure before drafting
4. Draft section by section - write incrementally
5. Review and refine
## Use Cases
- Technical specs
- DR plans
- Onboarding guides
- API documentation
- Runbooks
