# Domain Modeling
## Overview
Helps design clean domain models with TypeScript. Strict type discipline, clean interface boundaries, and honest code.
## Principles
- Types should describe the domain truthfully
- Interfaces should be minimal and focused
- Domain logic should be pure when possible
- Side effects should be at the edges
