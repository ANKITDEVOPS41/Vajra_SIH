# Superpowers - Agentic Development Methodology

## Overview
Superpowers transforms how AI coding agents work. Instead of jumping straight into writing code, it enforces a disciplined workflow.

## Core Workflow
1. **Clarify** - Understand what the user is really trying to do
2. **Spec** - Tease out a specification, show it in digestible chunks
3. **Plan** - Create an implementation plan clear enough for execution
4. **Execute** - Launch subagent-driven development through each task
5. **Review** - Inspect and review work, continue forward

## Embedded Skills
### Testing
- test-driven-development: RED-GREEN-REFACTOR cycle
### Debugging
- systematic-debugging: 4-phase root cause process
- verification-before-completion: Ensure it is actually fixed
### Collaboration
- brainstorming: Socratic design refinement (USE BEFORE ANY CREATIVE WORK)
- writing-plans: Detailed implementation plans
- executing-plans: Inline plan execution with final review
- dispatching-parallel-agents: Concurrent subagent workflows
- requesting-code-review: Pre-review checklist
- receiving-code-review: Responding to feedback
- using-git-worktrees: Parallel development branches
- finishing-a-development-branch: Merge/PR decision workflow
- subagent-driven-development: Fast iteration with two-stage review
### Meta
- writing-skills: Create new skills following best practices
- using-superpowers: Introduction to the skills system

## Principles
- True RED/GREEN TDD
- YAGNI (You Aren't Gonna Need It)
- DRY (Don't Repeat Yourself)
