# PPT Generation
## Overview
Use when the user requests to generate, create, or make presentations (PPT/PPTX). Creates visually rich slides by generating images for each slide and composing them into a PowerPoint file.
## Process
1. Understand presentation topic and audience
2. Create slide outline
3. Generate slide images
4. Compose into PPTX file
