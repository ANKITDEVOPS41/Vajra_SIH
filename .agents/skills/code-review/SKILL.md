# Code Review
## Requesting Review Checklist
1. Self-review diff first
2. Ensure all tests pass
3. Check for debug code, TODOs, commented-out code
4. PR description explains WHY not just WHAT
5. Keep PRs focused and sized
## Receiving Review
1. Read ALL feedback before responding
2. Assume good intent
3. Ask for clarification if unclear
4. Explain reasoning with evidence if disagreeing
## Review Focus
- Correctness, Readability, Performance, Security, Testing, Maintainability, Consistency
