# Request Refactor Plan
## Overview
Generates a refactoring plan before any code changes. Prevents making things worse in the name of making them better.
## Plan Includes
1. Current state analysis
2. Desired state description
3. Step-by-step refactoring sequence
4. Risk assessment for each step
5. Rollback strategy
