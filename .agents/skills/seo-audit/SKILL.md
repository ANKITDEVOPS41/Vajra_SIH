# SEO Audit
## Checklist
- Title tags - proper descriptive titles
- Meta descriptions - compelling and accurate
- Heading structure - single h1, proper hierarchy
- Semantic HTML - appropriate HTML5 elements
- Performance - fast page load times
- Mobile responsiveness
- Open Graph tags
- Structured data
- Internal linking
- Image alt text
