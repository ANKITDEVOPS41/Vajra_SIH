# Brainstorming
## When to Activate
- BEFORE creating new features
- BEFORE building new components
- BEFORE adding new functionality
- BEFORE modifying existing behavior
## Process
1. Explore Intent - what is the user really trying to achieve
2. Clarify Requirements - must-haves vs nice-to-haves
3. Surface Constraints - technical, time, resource
4. Generate Options - multiple approaches not just one
5. Evaluate Trade-offs - complexity, maintainability, performance
6. Converge - agree on approach before writing ANY code
