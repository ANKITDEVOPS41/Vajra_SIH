# Implement
## Overview
Translates specifications and plans into working code following project conventions.
## Process
1. Read and understand the spec completely
2. Identify the implementation approach
3. Write tests first (TDD)
4. Implement incrementally
5. Verify against spec
6. Clean up and refactor
